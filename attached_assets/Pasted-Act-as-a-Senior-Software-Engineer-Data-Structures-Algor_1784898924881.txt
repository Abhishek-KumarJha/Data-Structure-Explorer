# CP Companion – Competitive Programming Practice & Analysis System

## Objective

Develop a modern web application that helps competitive programmers organize, search, practice, and analyze coding problems.

The project is for a university Data Structures & Competitive Programming course, so the main focus should be demonstrating practical implementations of DSA concepts instead of just creating CRUD pages.

The application should look professional enough to include in a software engineering portfolio.
